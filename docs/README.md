# Offshore Platform Monitor — documentation

A Sigil Watch demo of live sensor monitoring on a fictional offshore oil & gas
platform. Start with the overview, then go to whichever part you need.

| Document | What it covers |
|---|---|
| [Overview](OVERVIEW.md) | What the demo is, who it's for, what it shows, and a five-minute demo script |
| [Features](FEATURES.md) | Every part of the screen and how it behaves |
| [Architecture](ARCHITECTURE.md) | Files, data flow, the simulator, the alert engine, and how to point it at a real service |
| [API reference](API.md) | The `PlatformAPI` calls and the shape of every object they return |
| [UI design](UI_DESIGN.md) | Layout, colour and shape encoding, tokens, breakpoints, accessibility |
| [Scenarios](SCENARIOS.md) | The nine scripted events on the 10-minute loop, sensor by sensor |
| [Sensor catalog](SENSOR_CATALOG.md) | The six categories and 49 sensor types: what each measures and what it tells you |
| [Roadmap and open questions](ROADMAP.md) | Known limitations, next steps, questions for a real deployment |

**Everything here is simulated.** The platform, its sensors, readings and
thresholds are fictional demo values, not engineering, regulatory or safety
limits.
